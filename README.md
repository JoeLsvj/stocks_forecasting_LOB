# stocks_forecasting_LOB
This repository contains all the material for publication...

- in CNN_LSTM.py: encoder of the deeplob model
- in LSTM.py: LSTM solo models
- in utils.py: function to train and test the model
- in build_timeseries: classes to construct the sliding window dataset and the dataloaders
- in main_notebook.ipynb: some model tested on the lobster data for few epochs (regression on the immediate successive tick)
- in main_notebook_helsinky: some model tested on the FI2010 data for few epochs (regression on the immediate successive tick)
- main.py -> for orfeo running, now empty
- CNN.py: RGB CNN model, not yet implemented
- transformer.py: transformer model, not yet implemented
